# Матрица доступа и требования к защите данных

## 1. Роли пользователей
1. **Кассир (`pos_cashier`)** - создает чеки, добавляет товары, принимает оплату, закрывает смену.
2. **Менеджер магазина (`store_manager`)**- просматривает отчеты по магазину, управляет сменами, меняет цены.
3. **Аналитик (`analyst`)** - строит отчеты, видит данные без телефонов клиентов и имен сотрудников.
4. **Администратор (`db_admin`)** - управляет схемой, ролями, делает резервную копию данных.

## 2. Матрица доступа (Права на таблицы)

| Сущность | Категория данных | Роль | Разрешённые операции | Запрещённые операции | Основание ограничения |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `customers` | **Персонал.данные** | `analyst` | `SELECT (customer_id, bonus_points)` | `SELECT (phone)`, `UPDATE`, `DELETE` | 152-ФЗ |
| `employees` | **Персонал.данные** | `analyst` | Нет доступа | Любые операции | 152-ФЗ |
| `receipts` | Ком. тайна | `pos_cashier` | `INSERT`, `SELECT` (за свою смену) | `DELETE`, `UPDATE` суммы | Бизнес-правило |
| `products` | Ком. тайна | `store_manager` | `SELECT`, `UPDATE` (только цена) | `DELETE`, `DROP` | Должностная инструкция |
| `audit_log` | Служебная | `db_admin` | `SELECT` | `UPDATE`, `DELETE` | Защита от подмены логов |

## 3. Требования к защите данных
- **Обезличивание:** При выгрузке данных для аналитиков (роль `analyst`) номера телефонов в таблице `customers` маскируются.
- **Журналирование (Аудит):** Любые изменения (`UPDATE`, `DELETE`) в таблицах с Персонал.данными (`customers`, `employees`) записываются в таблицу `audit_log` с указанием времени, пользователя и старых/новых значений.
- **Шифрование:** Пароли сотрудников и номера телефонов клиентов должны передаваться по защищенному каналу и храниться в зашифрованном виде.
- **Резервное копирование:** Полная копия БД делается ежедневно в 02:00 ночи. Срок хранения бэкапов — 30 дней. Логи аудита хранятся 2 года.
